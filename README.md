# Mini WireGuard

> [!WARNING]
> Work in progress. This is not a production-ready WireGuard implementation or
> a replacement for WireGuard.

Mini WireGuard is a userspace implementation of the WireGuard protocol, written
from scratch in Go. The current tunnel is not encrypted yet: IP packets are sent
as plaintext UDP payloads.

## Current state

The program currently:

- creates a Linux TUN interface named `tun0` using `IFF_TUN | IFF_NO_PI`;
- assigns the configured IPv4 address, sets the MTU to `1420`, and brings the
  interface up;
- parses and validates IPv4 packets;
- forwards IPv4 packets read from TUN as UDP payloads to a configured peer;
- receives IPv4 packets over UDP and writes them to TUN;
- includes tested helpers for parsing ICMP echo requests and building replies;
- validates and calculates IPv4 and ICMP checksums.

The unencrypted tunnel milestone has been verified with `ping` and TCP traffic
generated by `iperf3` between two network namespaces. Packet captures on `tun0`
and `veth` confirmed that IP packets are carried as UDP on the underlay.

## Running

The program is Linux-only and needs permission to create and configure a TUN
interface, for example by running the built binary with `sudo`.

```sh
mage build
sudo ./bin/wireguard-mini \
  -listen 192.0.2.1:51820 \
  -peer 192.0.2.2:51820 \
  -tun-address 10.0.0.1/24
```

The peer must run another instance with the listen address, peer endpoint, and
TUN address reversed for its side of the tunnel.
